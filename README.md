# Plusieurs vies, un cap : le carnet

Carnet d'accompagnement de la série de podcasts **Plusieurs vies, un cap** : 8 épisodes pour les personnes multipotentielles qui font un bilan de leurs compétences et de leurs aspirations, puis choisissent une orientation réaliste face au marché de l'emploi.

Le carnet compte **8 pages, une par épisode**. Chaque page contient les exercices de l'épisode, et la bibliographie de l'épisode figure en bas de page.

## Contenu

| Page | Épisode | Exercices principaux |
| --- | --- | --- |
| 1 | Multipotentiel, pas dispersé | intérêts, forces, étiquettes réécrites, modèle de travail, regret, deux situations clés |
| 2 | Relire son parcours | frise, courbe d'énergie, fil rouge, phrase « Dans toutes mes vies, je cherche à… » |
| 3 | Inventaire des compétences | verbes d'action (données, personnes, choses), compétences invisibles, 5 mini-récits STAR |
| 4 | Ce qui t'anime vraiment | valeurs, ancres de carrière, besoins de base, curiosités, phrase « Ce qui m'anime, c'est… » |
| 5 | Les contraintes réelles | marché de l'emploi, budget, tableau rouge, orange, vert |
| 6 | Croiser le tout | tableau de croisement, pistes hybrides, plans Odyssée, 3 fiches de pistes finales |
| 7 | Tester avant de sauter | entretiens exploratoires, mini-missions, immersion, formation courte, journal de tests |
| 8 | Choisir et avancer | grille de décision, plan sur 90 jours, phrases si-alors, lettre à soi |

## Utilisation

- Ouvrir `index.html` dans un navigateur. Aucune installation, aucun serveur.
- Remplir à l'écran : les réponses sont enregistrées dans le navigateur de l'ordinateur utilisé (stockage local). Elles ne sont envoyées nulle part.
- Imprimer : le bouton « Imprimer le carnet » met chaque page sur sa feuille. Le carnet peut aussi s'imprimer vide pour écrire au stylo.
- Effacer : le bouton « Effacer mes réponses » supprime les réponses enregistrées dans ce navigateur.

## Sources et limites

- Chaque page cite ses sources en bas de page. Les chiffres du marché de l'emploi sont datés (Insee, 3<sup>e</sup> trimestre 2026 ; France Travail, Besoins en main-d'œuvre 2026) et seront à mettre à jour.
- Les bibliographies des épisodes 1, 3 et 4 ne contiennent pas de liens : elles reprennent les références citées dans les épisodes.
- La page 1 a été reconstruite à partir des thèmes de l'épisode 1.
- Pour les droits, les aides et les formations, le conseiller France Travail reste l'interlocuteur pour confirmer chaque situation.
